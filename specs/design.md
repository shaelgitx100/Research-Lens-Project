# ResearchLens implementation design

The demo workspace is explicitly separated from authenticated MongoDB data. OpenAlex discovery uses public metadata through the server. Analysis is conservative, source-text-based and marks missing information; gap and question templates are hypotheses, not scientific conclusions. The React client provides responsive workspace navigation and visual analytics. Express validates requests, limits traffic, hashes passwords, signs tokens, scopes project and paper queries to owners, and never returns password hashes. MongoDB and a strong JWT secret are configured through environment variables. If MongoDB is absent, the server remains available for metadata discovery and the frontend offers a clearly labeled local demo rather than claiming persistence. PDF extraction, email reset, external AI and complete citation enrichment are not implemented in this prototype.
